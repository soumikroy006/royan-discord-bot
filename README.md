#  Royan - Discord Welcomer Bot

Royan is a stylish and advanced Discord welcome bot built using Python and discord.py.  
It automatically greets new members with modern embed messages and sends goodbye messages when members leave the server.

---

##  Features

-  Stylish welcome embeds
-  Goodbye/leave embeds
-  User avatar support
-  Join position tracking
-  Account age detection
-  Member role display
-  Fast and lightweight
-  Proper Discord intents support
-  Clean and professional UI

---

## 🛠️ Technologies Used

- Python
- discord.py
- Discord API

##  Installation

###  Clone Repository

```bash
git clone https://github.com/yourusername/royan-discord-bot.git
cd royan-discord-bot
```

---

###  Install Dependencies

```bash
pip install discord.py
```

---

###  Configure Bot

Open:

```bash
welcomer-bot.py
```

Replace:

```python
WELCOME_CHANNEL_ID = YOUR_CHANNEL_ID
```

with your Discord channel ID.

Also replace:

```python
bot.run("YOUR_BOT_TOKEN")
```

with your bot token.

---

##  Enable Intents

Go to Discord Developer Portal:

* Open your bot application
* Go to **Bot**
* Enable:

  *  SERVER MEMBERS INTENT

---

##  Run the Bot

```bash
py welcomer-bot.py
```
